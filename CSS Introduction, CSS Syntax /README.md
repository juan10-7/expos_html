# CSS Introduction

## ¿Qué es CSS?

CSS (Cascading Style Sheets) es un lenguaje que se utiliza para dar estilo a las páginas web. Permite cambiar colores, tamaños, fuentes y organización del contenido.

---

## ¿Para qué sirve CSS?

* Cambiar colores 
* Modificar textos 
* Organizar la página 
* Hacer diseños modernos 

---

## Formas de usar CSS
### 1. CSS en línea

Se aplica directamente dentro de una etiqueta HTML.


<p style="color: red;">Texto en rojo</p>


---

### 2. CSS interno

Se usa dentro de la etiqueta `<style>`.


<style>
p {
  color: blue;
}
</style>


---

### 3. CSS externo

Se usa un archivo aparte `.css`.


<link rel="stylesheet" href="styles.css">

---

## Conclusión

CSS es esencial para hacer páginas web atractivas y organizadas.

# CSS Syntax

##  ¿Qué es la sintaxis de CSS?

La sintaxis de CSS es la forma en que se escriben los estilos.

---

## Estructura

```css
selector {
  propiedad: valor;
}
```

---

## Ejemplo

```css
h1 {
  color: green;
  text-align: center;
}


## Explicación
* **Selector:** elemento HTML (h1)
* **Propiedad:** lo que quieres cambiar (color)
* **Valor:** el cambio (green)



##  Conclusión

La sintaxis de CSS permite aplicar estilos de forma clara y organizada.
